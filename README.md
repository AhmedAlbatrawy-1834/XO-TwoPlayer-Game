# 🕹️ XO Game (Tic-Tac-Toe)

A simple **two-player console-based Tic-Tac-Toe game** built using C#.  
This project was created as part of my self-learning journey to practice **Object-Oriented Programming (OOP)** and fundamental coding skills.

---

## 🚀 Features

- Two-player gameplay (played on the same computer)
- Clean and modular code using OOP concepts
- Input validation and user interaction via the console
- Simple 3x3 board display with real-time updates

---

## 🛠️ Technologies Used

- C#
- .NET Console Application

---

## 🎯 Purpose

This project was built to:

- Strengthen understanding of **OOP** in C#
- Practice writing reusable and organized code
- Improve logic and control flow using conditions, loops, and arrays
